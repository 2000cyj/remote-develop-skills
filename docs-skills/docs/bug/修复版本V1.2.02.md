## 二、已修复项确认

### BUG-001 ✅ 店铺导出「关联主体」列已合并

- 重新导出店铺信息，检查 xlsx：同一主体（test公司）的 4 行「关联主体」单元格已**垂直合并**为合并单元格（`[M]test公司`），符合需求 3.1.2「上下相邻行相同的做合并行处理」。
- 涉及后端 `StoreManageServiceImpl` 改动。

### BUG-003 ✅ 公司导出「所属部门」已转中文

- 重新导出公司信息：「所属部门」列现为 `市场部，电商一部，电商二部`、`电商一部，电商二部` 等**中文显示文本**，不再是字典原始码 `11，121，122`。

### BUG-006 ✅ 公司筛选区已补筛选项

- 展开公司列表筛选区：已出现**「资料完整状态」「具有开店资质」**两个筛选项（UI 已验证），符合需求 3.3.2「筛选区增加对应筛选项」。

### BUG-009 ✅ 保证金阈值提示已显示具体金额

- 保证金阈值字典已配置（当前阈值 **10000**），输入超额保证金时提示将显示具体阈值金额，不再显示空的「（元）」。
- 附：输入低于阈值的金额不弹提示，逻辑正常（测试 9999 < 10000 未触发，符合预期）。

### 观察项 ✅ 税种核定信息税种已转中文

- 原导出 `personal_income_tax/工资薪金所得/月` 现为 `个人所得税/工资薪金所得/月`。
