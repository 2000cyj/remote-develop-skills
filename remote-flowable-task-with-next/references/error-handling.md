## 16. 错误和注意事项

### 16.1 常见参数错误

- `taskId` 为空：后端工具类会抛出“流程任务ID不能为空”。
- `operationId` 为空：受保护调用会失败。
- `twoLevelId` 为空：受保护调用会失败。
- `taskId` 不存在：Flowable 会返回任务不存在。
- 当前用户不是任务处理人：权限校验失败。
- 退回目标节点不在允许列表：Flowable 拒绝退回。
- 使用错误的 `outcome`：业务服务可能拒绝或按通过分支处理。

### 16.2 不要混淆的字段

| 字段 | 不能混淆为 |
| --- | --- |
| `taskId` | 业务单据号、`businessKey`、流程实例 ID。 |
| `operationId` | 业务单据号。它是一次审批操作的幂等号。 |
| `twoLevelId` | 流程定义 Key。它是业务调用点的二级模块标识。 |
| `targetActivityId` | 目标节点名称。它是 BPMN 节点 ID。 |
| `variables` | 业务接口外层对象。它只表示流程变量。 |

### 16.3 事务边界

`completeTaskWithNext` 负责 Flowable 任务和流程结果，业务服务通常在同一个业务事务中继续更新本地数据。调用方需要明确：

- Flowable 成功后，本地业务更新失败时如何补偿；
- 前端超时重试时如何复用 `operationId`；
- 下一节点待办推送失败时是否重试；
- 流程已结束时是否更新为业务完成状态。
